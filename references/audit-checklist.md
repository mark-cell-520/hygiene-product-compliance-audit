## 1. 主体资质（第 1 层）
- [ ] 生产企业持有效《消毒产品生产企业卫生许可证》，生产类别覆盖本产品
- [ ] 一企一生产场所一证；多场所/分厂须分别取证
- [ ] **委托生产/OEM**：产品责任单位为**委托方**（WS 628 3.2）；代工厂持有效许可证且生产类别覆盖；标签同时标注委托方与实际生产企业
- [ ] **若属第一/二类**：卫生安全评价报告已备案，备案在有效期内（一类四年），且**已按 GB 38598 第1号修改单（2025-05-01）更新备案与标签**
- [ ] 若属第三类（普通/抑菌卫生巾、护垫、纸尿裤、尿布、普通湿巾）：确认无需备案，未误当备案产品
- [ ] **企标**已在企业标准信息公共服务平台自我声明公开，且不低于国标（2017 年起取消备案，改为自我声明）
- [ ] 企标/包装明示指标**未低于**强制标准（否则按强制标准判定）

## 2. 检测报告（第 2 层）
### 2.1 基础包（所有产品）
- [ ] GB 15979-2024 全项：微生物（细菌/真菌菌落总数、特定微生物 4 项）、理化（pH、可迁移荧光、铅砷汞按品类、环氧乙烷残留如适用）
- [ ] 毒理学试验（首次上市）：按品类选做皮肤刺激/眼刺激/阴道黏膜刺激/皮肤变态反应
- [ ] 性能标准：
  - 卫生巾/护垫：GB/T 8939 全项（偏差、吸水倍率、吸收速度、pH、甲醛、荧光、水分、背胶强度）
  - **女性卫生裤（安心裤/裤型卫生巾）：GB/T 39391-2020 全项（吸收速度 ≤60s、pH 4.0~9.0、甲醛 ≤75.0、可迁移荧光、交货水分 ≤10.0%）——注意它不走 GB/T 8939，指标比 8939-2025 宽；甲醛取样核对"包含各层材料"与剪去边部松紧带**
  - 婴儿纸尿裤：GB/T 28004.1 全项（吸收速度一/二次、回渗量、渗漏量、防侧漏、丙烯酰胺、邻苯、致癌芳香胺、重金属）
  - 成人纸尿裤：GB/T 28004.2 全项
  - 纸巾：GB/T 20808（亮度、荧光、微生物、原料合规）
  - 湿巾：GB/T 27728.1/.2/.3 对应部分
- [ ] 报告结论为合格且在有效期内；抽样按 GB 15979 附录 B/E（同批号 3 个运输包装至少 6 件最小销售包装）
- [ ] **批次一致性**：所有检验项目原则上同一批次完成（WS 628 5.2）；补项换批次的已重测有效成分含量、pH 及最强抗力微生物试验
- [ ] 消毒级产品：初始污染菌 ≤10000 CFU/g + 消毒效果杀灭对数值 ≥3.00 + EO 残留（消毒后≤250、上市时≤10 μg/g）

### 2.2 抑菌产品追加包（宣称抑菌时必做）
- [ ] **成品抑菌性能报告**：标称菌种**全项**（标 3 种测 3 种），与检测机构**书面约定取样部位**（抑菌功能所在层）
- [ ] **稳定性报告**：抑菌作用室温保持 ≥1 年（加速试验可接受）
- [ ] **非溶出性鉴定**（成分在导流层/面层时）：浸泡法 + 抑菌环法；两法矛盾按溶出性判定
- [ ] **回渗液抑菌性试验**（导流层/面层抑菌）：12 片滤纸全无抑菌环；宣称的菌种都要测
- [ ] **溶出物毒理评价**：阴道黏膜刺激 + 皮肤刺激 + 皮肤变态反应，或安全性风险评估
- [ ] 限定值核对：氯己定类（手/皮肤 ≤45.0、黏膜 ≤5.0）、三氯生（≤20.0/≤3.5）、苯扎溴铵/氯铵（≤5.0/≤2.0）g/L
- [ ] 若宣称"长效/持久抑菌"：吸收法细菌 ≥70%、真菌 ≥60%；振荡法 ≥99%
- [ ] **毒理试验重新做过**（添加抑菌成分属原材料变化，GB 15979 6.3.1 要求重做）
- [ ] 供应商材料报告与成分安全资料（MSDS）已归档，未当作上市依据使用

## 3. 标签审核（第 3 层）
- [ ] 必标项齐全（名称、净含量、生产企业名称地址联系方式、卫生许可证号、生产日期及有效期/批号及限期使用日期、贮存条件、执行标准编号）
- [ ] **GB 38598 第1号修改单（2025-05-01）**：抗（抑）菌制剂警示语"本品不是药品，不具有治疗、护理、保健作用"为**黑体或字号大于使用说明及其他注意事项**；文字高度 **≥1.8mm**；商标名无暗示疗效的谐音/图形
- [ ] 抑菌产品：标注**抑制微生物类别**（菌种与检测报告一致）+ 有效抑菌结构或部位
- [ ] 若用表 2 限用物质：包装**标识该物质**（GB 15979 9.3）
- [ ] 卫生湿巾：有效成分及含量、杀灭微生物类别、使用范围、主要原料
- [ ] 抗（抑）菌制剂："本品不是药品，不具有治疗、护理、保健作用"警示语 + "不应用于性生活中对性病的预防"（阴部黏膜用）
- [ ] 消毒级：销售包装"消毒级"+消毒方法+消毒日期+杀灭/抑制微生物类别；运输包装"消毒级"+生产日期及有效期/批号及限用日期
- [ ] 违禁词扫描（跑 scripts/label_scan.py）：0 命中
- [ ] 明示指标自检：包装/详情页写的每个数字（长度、吸收量、抑菌率）都有报告支撑——抽检按"明示要求高于标准时按明示判"
- [ ] **安心裤专查**：每包片数 ≥5 时每片独立包装（GB/T 39391-2020 4.3）；规格标注（S/M/L/XL 的适用臀围与腰围最大值）与实测一致
- [ ] 宣传口径核对："实验室条件""特定菌种"等限定语是否齐全；有无"平衡菌群""祛味除臭""物理隔菌"等无依据宣称
- [ ] 文字高度 ≥1.8mm；外文/拼音不大于中文
- [ ] 无疾病名称、无治疗暗示、无绝对化用语

## 4. 过渡期核对
- [ ] 生产日期在 2025-05-01 之后：标签符合 GB 38598 第1号修改单
- [ ] 生产日期在 2025-07-01 之后：执行 GB 15979-2024（不是 2002 版）
- [ ] 生产日期在 2025-10-01 之后：湿巾按 GB/T 27728.1/.2/.3-2024（不是 2011 版）
- [ ] 生产日期在 **2027-01-01 之后**：卫生巾/护垫按 **GB/T 8939-2025**（注意：吸收倍率改用标准合成试液，与旧版数值不可直接比较；pH 收紧至 4.0-7.5；甲醛 ≤6.0 mg/kg；新增邻苯、重金属、致癌芳香胺；吸收速度 ≤50s 与回渗量 ≤3.0g **仅考核全长 ≥200mm 的卫生巾**）
- [ ] 报告上的吸收速度/回渗量是否被写成"≤20s""≤0.5g"——**这是检测机构解读稿的错误数字**，官方口径是 ≤50s / ≤3.0g
- [ ] 详情页若写了"棉芯长度 ××mm"：该数字即成为判定线（国标不考核芯体长度，但明示要求高于标准时按明示判）
- [ ] 2026 年立项新品：生命周期跨越 2027-01-01 的，是否已按新标设计
- [ ] 婴儿纸尿裤新品：GB/T 28004.1 修订计划已立项（拟发布后 12 个月实施），供应商技术协议是否已写入甲酰胺管控
- [ ] 旧版产品仍在售：只允许在标示有效期/保质期内销售
