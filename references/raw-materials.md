# 原材料端标准库（供应商审核与来料检验用）

> 用途：审核导流层、绒毛浆、高吸收性树脂、面层等原材料时，判断供应商该给什么报告、指标该是什么。
> 关键认知：**原材料合规 ≠ 成品合规**。原料报告是供应链证据，成品报告才是上市依据。

---

## 1. 绒毛浆 GB/T 21331-2021《绒毛浆》

2021-03-09 发布，2022-04-01 实施，代替 GB/T 21331-2008。适用于生产一次性使用卫生用品的原料绒毛浆。

### 2021 版主要变化（相比 2008 版）
- 修改 D65 亮度、紧度、耐破度、干蓬松度、吸水时间、吸水量、尘埃度要求
- **二氯甲烷抽出物 → 丙酮抽出物**（环保性改进，注意别拿旧方法的报告）
- **新增**：可迁移性荧光物质、可吸附有机卤素（AOX）、铅（Pb）、砷（As）、镉（Cd）、汞（Hg）含量要求及测定方法
- "卫生指标"改为"**微生物指标**"
- 干蓬松度下限**由 2008 版 ≥15 cm³/g 提高**（修订前后对比已由标准前言确认"提高了干蓬松度与吸水时间要求"；现行版具体数值的二手转述有 **≥17 cm³/g 与 ≥19.0 cm³/g 两个版本**，以标准原文表 1 影像页为准）
- 吸水时间**由 2008 版收紧**（二手转述有 **≤3 s 与 ≤5 s 两个版本**，同样以原文表 1 为准）
- 可迁移性荧光物质明确要求"**不应有**"

### 结构要点
- 5.1 理化性能指标应符合表 1
- 5.2 **微生物指标执行 GB 15979 的规定**（不单独设限）
- 5.3 浆板不应有肉眼可见的金属杂质、沙粒等异物，无明显纤维束

### 表 1 理化指标（2021 版）

| 指标名称 | 单位 | 要求 |
|---|---|---|
| 定量偏差 | % | ±5.0 |
| 紧度偏差 | % | ±5.0 |
| 耐破度 | m²/500 g | 0.4~1.0 mm 与 >1.0~5.0 mm 分档设限（检验对象为绒毛浆浆板，可按订货合同生产其他规格） |
| D65 亮度（正反面平均） | % | 有上限要求（谱系数值见标准原文表 1） |
| 干蓬松度 | cm³/g | 转述 ≥19.0，**以标准原文为准** |
| 吸水时间 | s | 转述 ≤5，**以标准原文为准** |
| 吸水量 | g/g | 有下限要求（谱系数值见标准原文表 1） |
| 可迁移性荧光物质 | — | **不应有** |
| 丙酮抽出物 | % | 有上限要求 |
| AOX | mg/kg | 有上限要求 |
| 铅（Pb） | mg/kg | 有上限要求 |
| 砷（As） | mg/kg | 有上限要求 |
| 镉（Cd） | mg/kg | 有上限要求 |
| 汞（Hg） | mg/kg | 有上限要求 |
| 尘埃度 | mm²/500 g 等 | 分档设限 |
| 交货水分 | % | 有上限要求 |

**数字口径分歧（诚实标注）**：干蓬松度有 ≥17 cm³/g 与 ≥19.0 cm³/g 两个二手转述，吸水时间有 ≤3 s 与 ≤5 s 两个转述——都未回到标准原文表 1 影像页核对。**已由标准前言确认的事实**：2008 版干蓬松度为 ≥15 cm³/g，2021 版该项是"提高"不是"放宽"。审核时**要求供应商按原文件逐项对表**，不引用二手数字当判定依据。

**AQL 抽样（7.3）**：干蓬松度、吸水时间、吸水量、可迁移性荧光物质、AOX、重金属为 AQL 4.0；定量偏差、紧度、丙酮抽出物、尘埃度、耐破度、交货水分、D65 亮度、外观质量为 AQL 6.5。正常检验二次抽样方案，特殊检查水平 S-2。

## 2. 高吸收性树脂（SAP）GB/T 22875-2018

2018-06-07 发布，2019-01-01 实施，**全部代替** GB/T 22875-2008（卫生巾高吸收性树脂）和 GB/T 22905-2008（纸尿裤高吸收性树脂）。

- 现行有效；**2025-07-01 复审结论为"修订"，修订计划 20252839-T-607 正在征求意见**——关注后续新版
- **修订版（征求意见稿，2026-07 公开）已明确的 7 项技术变化**，来源：标准编制说明（征求意见稿）+"本标准规定的主要内容有：残留单体（丙烯酸）、挥发物含量、pH、粒度分布、密度、返黄值、吸收速度、吸收量、保水量、加压吸收量、可萃取物含量、**重金属含量**、外观、**消臭效果和抑菌性能**等"：
  1. 增加术语与定义章节
  2. **新增女性卫生裤和宠物尿裤（垫）用 SAP 的要求和试验方法**（适用范围扩张）
  3. 更改 pH 和外观指标要求
  4. **新增重金属含量要求**（原材料端提前卡控——婴儿纸尿裤/卫生巾国标已限重金属，原料端补位）
  5. **新增明示具有消臭效果、抑菌性能产品的参考评价或测定方法**（消臭型 SAP 过去无统一评价路径）
  6. 更改标准合成试液配方与物理性能要求（附录 K）
  7. 更改规范性引用文件
- 修订背景原文提到：消臭型/抗抑菌 SAP "已具有一定市场规模，但由于缺乏统一、科学的性能评价标准，这对消费者的选择和市场的监管造成了困扰"
- 主要提高了残留单体（丙烯酸）安全指标要求，调整吸收速度指标要求和挥发物含量测定方法，增加返黄值
- 医护级团标 T/NAHIEM 37 额外要求：**SAP 中丙烯酸残留单体 ≤600 mg/kg**（严于国标三档，作供应链加分项；注意那是对医护级认证的要求，不是国标要求）
- GB/T 22875-2018 适用范围：**聚丙烯酸盐类**高吸收性树脂；其他一次性卫生用品用 SAP 可参考本标准
- 检验批：同一原料、同一工艺、同一时间段，**每批不超过 500 t**；从同批次不少于 3 个包装袋均匀取样 1 kg；任一项目不合格即判批不合格

**审核口径（对本轮新增的应对）**：现在接到的 SAP 报告若同时报"消臭""抑菌"性能，现行 2018 版标准里**没有**这两项的判定依据——别把供应商自定的消臭率/抑菌率当合格判定；应按 GB 15979-2024 附录 E 在**成品端**另行验证。

### 表 1 技术指标（已核实，来源：标准原文转录）

| 指标 | 单位 | 婴儿纸尿裤（片、垫）用 SAP | 成人纸尿裤（片、垫）用 SAP | 卫生巾（护垫）用 SAP |
|---|---|---|---|---|
| 残留单体（丙烯酸） | mg/kg | **800** | **1 000** | **1 000** |
| 挥发物含量 | % | 10.0 | 10.0 | 10.0 |
| pH | — | 4.0~8.0 | 4.0~8.0 | 4.0~8.0 |
| 粒度分布（<106 μm / 其中 <45 μm） | % | 10.0 / 1.0 | 10.0 / 1.0 | 10.0 / 1.0 |
| 密度 | g/cm³ | 0.3~0.9 | 0.3~0.9 | 0.3~0.9 |
| 返黄值（参考指标，不作合格判定） | % | 40.0 | 40.0 | 40.0 |
| 吸收速度 | s | 150 | 150 | 150 |
| 吸收量（合成液/生理盐水） | g/g | 20.0 / 40.0 | 20.0 / 40.0 | 20.0 / 40.0 |
| 保水量 | g/g | 20.0 | 20.0 | 20.0 |
| 加压吸收量 | g/g | 10.0 | 10.0 | 10.0 |

| 外观 | — | 色泽均一 | 色泽均一 | 色泽均一 |

**审核口径**：
- 残留单体限值**按用途分三档**：婴儿用最严（800），成人与卫生巾用 1 000。拿报告先看送检的是哪一档
- 返黄值是参考指标，供应商拿它当噱头时要说明"不作合格判定"
- 检验批规定：同一原料、同一工艺、同一时间段，每批不超过 500 t；从不少于 3 个包装袋均匀取样 1 kg

### 审核要点
1. 要供应商提供 SAP 残留单体（丙烯酸）报告
2. 婴儿纸尿裤产品端还要按 GB/T 28004.1 检丙烯酰胺（与 SAP 残留单体丙烯酸是两个项目，别混）
3. 新华网 2026 年报道指出：GB/T 28004.1-2021 **未对甲酰胺设检测项目和限量**，但多品牌纸尿裤检出甲酰胺，欧盟列为 1B 类生殖毒性物质、已列入我国《化妆品禁用原料目录》。这是**现行标准盲区**，出口欧盟或做高端定位需提前管控

## 3. 面层与导流层材料

### 面层材料 GB/T 30133-2022《一次性卫生用品用面层》
**版本链已核实（std.samr.gov.cn 标准详情页）**：GB/T 30133-**2013**《卫生巾用面层通用技术规范》（2013-12-17 发布、2014-12-01 实施）**已于 2023-02-01 废止**，被 **GB/T 30133-2022《一次性卫生用品用面层》全部代替**（2022-07-11 发布、**2023-02-01 实施**，现行）。

- 适用范围从"卫生巾用面层"扩到**纸尿裤（片、垫）、卫生巾（护垫）、妇女卫生裤等一次性卫生用品用面层材料**
- 归口 TC141（全国造纸工业标准化技术委员会），主管部门中国轻工业联合会
- 技术要求含 pH（附录 B 规范性方法：1.0±0.1 g 试样 + 100 mL 生理盐水，浸泡 10 min 后玻璃棒搅匀、G1 砂芯漏斗过滤，pH 计精度 0.01，标准缓冲液 4.00/6.86/9.18）等项；**具体限值表未取到原文影像，审报告时以供应商对原文件为准**
- 审核口径：**拿 2013 版报告就是拿废止标准报告**，现在（2026 年）应要求按 GB/T 30133-2022 出具；同时面层仍须满足 GB 15979-2024"不得添加可迁移性荧光增白剂"（4.3 c）

## 4. 导流层抑菌材料的专项（用户实际场景）

### 供应商应提供的资料
1. 材料级抑菌性能报告（**仅作供应链证据，不能上市用**）
2. **抑菌成分的化学名称、CAS 号、作用机理**
3. 成分安全资料：MSDS、毒理数据
4. 是否属于 GB 15979 表 2 限用物质（氯己定类、三氯生、苯扎溴铵/氯铵）
5. 是否为**溶出性**（要求供应商提供非溶出性鉴定，或自行按 GB 15979 E.6.6.1/E.6.7.1 做）
6. 材料的耐温、耐湿、老化数据（判断稳定性潜力）

### 审核红线
- 若成分属表 2 限用物质，成品包装**必须标识**（GB 15979 9.3）
- **PHMB（聚六亚甲基双胍）**：GB 15979-2024 表 2 只列了氯己定类、三氯生、苯扎溴铵/氯铵三种具名物质 + "国家规定的其他限用物质"兜底行，**未点名 PHMB**；PHMB 在《化妆品安全技术规范》中未被列入禁用化学物质（EU 允许作防腐剂至 0.1%~0.3%）
  → 结论口径：**不能等同于"可以用"**。PHMB 在一次性卫生用品里没有具名限值，使用时应按"国家规定的其他限用物质"从严处理，并提供毒理（GB/T 38496）+有效成分含量+稳定性全套数据；是否触发"消"字号其他规定**需向属地卫健部门确认**
- **严禁**：抗菌药物、抗真菌药物、抗病毒药物、激素类及同名原料（GB 15979 4.3 b）
- 非织造布/织物**不得添加可迁移性荧光增白剂**（4.3 c）

### 团标实测警示
T/CTAPI 征求意见稿验证的 25 款产品中，非溶出性鉴定呈**溶出性**的两款，抑菌有效部位分别是**导流层（W7）**和**芯片（W9）**，浸泡液抑菌率都 >99.9。

**推论**：导流层材料的高抑菌率报告，很可能同时是溶出性的信号。要求供应商提供非溶出性证据，别只看抑菌率数值。

## 5. 卫生巾（护垫）原料要求（团标 T/CTAPI 版本，与 T/NAHIEM 37 一致）

- 绒毛浆应符合 GB/T 21331
- 高吸收性树脂应符合 GB/T 22875
- 不应使用废弃回用的原材料
- 每片独立包装
- 两端封口牢固，使用中不应破裂
- 常规使用不产生位移，与内衣剥离不损伤衣物、无明显残留
- 离型纸不应自行脱落，能自然完整撕下

## 6. 微生物指标对比（原料 vs 成品，别混用）

团标 T/CTAPI 中卫生巾的微生物指标（注意与 GB 15979-2024 表 5 的差异）：

| 项目 | 团标限值 |
|---|---|
| 细菌菌落总数 | ≤100 CFU/g |
| 真菌菌落总数 | ≤50 CFU/g |
| 大肠菌群 | 不得检出 |
| 铜绿假单胞菌 | 不得检出 |
| 金黄色葡萄球菌 | 不得检出 |
| 溶血性链球菌 | 不得检出 |

而 **GB 15979-2024 表 5** 对妇女经期卫生用品（普通级）是细菌 ≤200、真菌 ≤100。

**团标比国标严一倍**——如果产品宣称按某团标执行，抽检就按团标判（判定规则：明示要求高于标准时按明示判）。绒毛浆的微生物指标则直接执行 GB 15979。

## 8. 待确认项

3. PHMB 在一次性卫生用品中的监管定性（表 2 未具名，"其他限用物质"是否覆盖需属地卫健口径）
4. FZ/T 64111-2024《卫生巾（护垫）用非织造布》的技术指标限值（标准号已由 std.samr.gov.cn 相近标准列表确认存在，具体数值未取）
