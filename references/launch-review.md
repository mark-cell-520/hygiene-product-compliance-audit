# 上市计划审核（Product Launch Review）

> 用于审核一个即将上市的卫生用品的完整计划，输出"能不能上、缺什么、卡在哪"。
> 比单产品 checklist 更前置：看的是**上市时间表 vs 合规就绪度**的匹配。

---

## 阶段 0：立项判定（决定后面所有工作量的三句话）

| 问题 | 回答 | 后果 |
|---|---|---|
| 产品宣称什么功能？ | 仅物理性能 | 走基础包 |
| | 宣称抑菌/抗菌 | **必须追加抗菌专项全套**（见 antimicrobial-audit.md），工作量×3 |
| | 暗示医疗功效 | 停止计划，此方向不能上市 |
| 产品属于消毒产品第几类？ | 第三类（普通/抑菌卫生巾、纸尿裤、纸巾） | 不需备案，只需生产企业的卫生许可证 |
| | 第一/二类（抗抑菌制剂、卫生湿巾） | 须卫生安全评价报告备案，加 2-4 周 |
| 执行标准的版本节点？ | 生产日期跨 2025-07-01 / 2027-01-01 / 2025-10-01 | 按当时有效版本判定，过渡期旧版可售至标示有效期止 |

**最常见的计划性错误**：立项时按普通卫生巾排期，临近上市才决定加"抑菌"卖点——此时稳定性报告（加速试验最短 14 天起步）、溶出物毒理、回渗液试验都要重做，且毒理试验因原材料变化必须重做。**功能定位必须在开模前定死。**

---

## 阶段 1：资质与主体
- [ ] 生产企业《消毒产品生产企业卫生许可证》在有效期内，且生产项目包含"卫生用品类"
- [ ] 一企一生产场所一证（多场所须分别取证）；委托生产须明确委托方与实际生产企业
- [ ] 若属第一/二类：卫生安全评价报告已备案（全国消毒产品网上备案信息服务平台）
- [ ] 企标已在企业标准信息公共服务平台自我声明公开，且不低于国标

## 阶段 2：检测就绪度（按宣称功能取包）

### 基础包（必做）
1. GB 15979-2024 微生物全项
2. GB 15979-2024 理化全项
3. 毒理试验（按品类）
4. 产品性能标准全项（GB/T 8939 或 28004.x 等）

### 抗菌追加包（宣称抑菌时）
5. 成品三菌抑菌率报告（取样部位书面约定）
6. 稳定性 ≥1 年（加速试验）
7. 非溶出性鉴定（导流层/面层抑菌必做）
8. 回渗液抑菌性试验
9. 溶出物毒理评价或风险评估
10. 长效抑菌（如宣称长效）

### 时间预估（第三方检测常规周期，需与实验室确认）
| 项目 | 典型周期 |
|---|---|
| 微生物 + 理化 | 5-10 工作日 |
| 性能标准 | 5-10 工作日 |
| 毒理试验 | 2-4 周（如含阴道黏膜刺激） |
| 稳定性（加速试验） | 14 天起（54℃），27℃ 常规更长 |
| 非溶出性鉴定 | 3-5 工作日 |
| 回渗液抑菌性 | 5-10 工作日 |
| 抑菌率全套 | 5-10 工作日 |

**排期铁律**：以最长项目（毒理、稳定性）倒推开工日，不要以最短项目排期。

## 阶段 3：标签与包装定稿
- [ ] 最小销售包装 + 运输包装必标项齐全
- [ ] 违禁词扫描 0 命中（`label_scan.py`）
- [ ] 功能宣称与检测报告菌种/数值一一对应
- [ ] 限用物质已标识（如用了表 2 物质）
- [ ] 抑菌产品已标"抑制微生物类别"+ 有效抑菌部位
- [ ] 文字高度 ≥1.8mm；外文/拼音不大于中文
- [ ] **包装定稿时间早于开机印刷时间**（改包装=重新制版，成本最高的一环）

## 阶段 4：宣传物料合规
- [ ] 详情页、主图、短视频脚本、直播口播稿全部过违禁词扫描
- [ ] 三条宣称权限线逐一核对（见 advertising-claims.md）
- [ ] 所有数字有报告对应
- [ ] 无绝对化用语、无同业贬低、无虚假人设
- [ ] "医用级""医护级""缓解痛经"等已彻底清除
- [ ] 中广协《卫生巾广告自律规则》自查（演示液体颜色、人体部位展示、刊播时段）
- [ ] 直播电商新规（2026-02-01 施行）合规：AI 生成内容、虚假人设、未核验主播身份

## 阶段 5：渠道与上市
- [ ] 电商平台上架资质逐平台确认当期规则
- [ ] 经营者（经销商/药店）采购时应索取：生产企业卫生许可证复印件 + 卫生安全评价报告或备案凭证复印件（加盖公章）——《消毒管理办法》第三十条
- [ ] 建立产品追溯与留样制度（GB 15979 附录 B/E：同批号至少 6 件最小销售包装，2/3 留样）
- [ ] 上市后抽检应对预案：渗透性能、标识、菌落总数是历史高发不合格项

## 上市就绪度打分

| 项 | 状态 | 备注 |
|---|---|---|
| 主体资质 | □齐 □缺 | |
| 检测报告（按功能包） | □齐 □缺_项 | |
| 标签定稿 | □过 □改 | |
| 宣传物料 | □过 □改 | |
| 渠道资质 | □过 □缺 | |

**判定规则**：
- 任一红线项缺失（无证、无强制检测、标签违规、宣称无依据）→ **不得上市**
- 只有整改项 → 可排整改后上市，给明确期限
- 全部就绪 → 出具可以上市的结论，并提示上市后义务（追溯、留样、抽检应对）

## 常见上市计划翻车点

1. **卖点后置**：立项按普通品排期，后期加抑菌卖点，导致稳定性+毒理全部重做，错过档期。
2. **排期按最短项目**：用微生物 5 天排上市日，忽略毒理 4 周和稳定性 14 天。
3. **包装先印后审**：包装制版印刷后才发现违禁词，返工成本最高。
4. **宣传口径与产品身份脱节**：产品是第三类普通卫生巾，宣传按消毒级/医用级讲。
5. **只审包装不审直播**：口播、背景板、商品标题、贴片是四个独立物料，常只审包装。
6. **忽略平台规则**：平台要求常严于法规且变动快，临近上架才发现缺资质。
7. **不留样不留追溯**：GB 15979 附录 B/E 的留样要求是抽检应对的底气，缺了就被动。
