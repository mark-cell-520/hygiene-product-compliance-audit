# 广告与营销宣称合规（产品出厂后的第二战场）

> 核心认知：**产品合规 ≠ 宣传合规**。检测报告解决了"能不能卖"，广告法解决"能不能说"。大量企业产品合格却在直播间翻车。
> 关键法条：《中华人民共和国广告法》第十七条、第九条、第二十八条、第五十五条、第五十八条；《消毒管理办法》第三十一条第二款。

---

## 1. 三条宣称权限线（直播/详情页/包装通用）

| 宣称方向 | 依据要求 | 能不能说 |
|---|---|---|
| 物理性能：吸收量、长度、透气性、材质、背胶、pH | 有对应检测项和检测报告 | **能说**，但每个数字都要能拿出报告对应项 |
| 抑菌 / 抗菌 | 产品须属可宣称该功能的类别 + 有检验依据（GB 15979 6.5.3 全套：初期 + 稳定性 + 毒理） | **有条件能说**——拿不出完整依据就不提 |
| 疾病治疗、医疗用语：缓解痛经、治炎症、止痒、消炎、医用级 | 没有依据可言，法律直接禁止 | **一句都不能说** |

**反扫逻辑**：凡无法用一份检测报告对应上的表述，宣传物料里就别出现。

---

## 2. 《广告法》第十七条：第二层杀伤力更大

> "除医疗、药品、医疗器械广告外，禁止其他任何广告涉及疾病治疗功能，并不得使用**医疗用语或者易使推销的商品与药品、医疗器械相混淆的用语**。"

多数人只看到第一层（不能讲治病），忽略第二层（不能让人混淆）：

| 说法 | 踩的是哪层 |
|---|---|
| 缓解痛经、改善妇科炎症、止痒 | 第一层：疾病治疗功能 |
| 医用级、医护级、药物卫生巾、临床验证、医院同款 | 第二层：易与药品/医疗器械混淆 |

**"医用级"不是可自证的等级**：医疗器械注册名称里没有"医用卫生巾"，只有"医用护理垫""医用吸收垫"（二类医疗器械）。市面上的"医护级卫生巾"依据的是团标 T/NAHIEM 37-2021，专家明确其"并非医用级卫生巾，也不是医用护理垫"——是营销词，而营销词正是第十七条盯着的东西。

### "医护级"本身已经在 2025 年被监管叫停（别再按"有团标认证就能标"审核）

经济观察报 2026-03-15《你买的"医用级卫生巾"是假的》采访认证方与品牌方得到的口径：

- **2025 年 8 月，市场监管总局认证监督管理司开会指出"医护级"等认证名称存在不当应用，禁止使用"医护级"等分级类名称进行认证宣传，并要求相关企业调整产品包装**——多家卫生巾品牌确认在 2025 年 8 月收到中卫安的更名通知
- 中卫安（北京）认证中心将"医护级认证"更名为**"特护产品认证"**，过渡期至 **2026 年 8 月**（现已届满）；特护产品与医护级产品标准细则相同，但依据的是**中卫安自行制定的认证标准**（认证中心级，不是团体标准），认证费用约 5 万元/企业
- 全国卫生产业企业管理协会侧的**特护卫生产品团体标准截至 2026-03 仍在制定中**
- 中卫安对电商页面"特护级＝医护级＋消毒级"的回应是：**不存在"特护级"的说法，准确说法是"特护认证产品"**；"某级别高于某级别"的客服话术同样无官方依据

**审核动作（硬红线）**：包装、商品标题、详情页、直播间口播出现"医护级"字样即判违规——不是"有团标认证就可以标"。改用中性表述"特护认证产品"时也必须同时说清它是**自愿性第三方认证**，不得与 GB 15979 法定分级（普通级/消毒级）并列比较、不得写成高于法定分级、不得暗示医用或医疗器械属性。

### 罚则档位（第五十八条第一款第二项）
| 情形 | 处罚 |
|---|---|
| 一般 | 责令停止发布、消除影响，处广告费用 **1-3 倍**罚款 |
| 广告费用无法计算或明显偏低 | **10-20 万元**罚款 |
| 情节严重 | 广告费用 3-5 倍；无法计算的 **20-100 万元**，可吊销营业执照 |

**关键风险点**："广告费用无法计算"——直播口播恰恰是最难核定广告费用的形态。一旦被认定违反第十七条，极易直接落到 **10 万元起的固定金额档**，而不是按一场直播的坑位费算。

## 3. 危险说法 vs 相对安全替代（对照表）

| 危险说法 | 问题出在哪 | 相对安全的替代 |
|---|---|---|
| 医用级 / 医护级 / 医院同款 | 医疗用语 + 无国标等级依据 | 报执行标准编号和检测项目，让参数说话 |
| 缓解痛经 / 治妇科炎症 / 止痒 / 消炎 | 第十七条明令禁止 + 《消毒管理办法》禁止暗示疗效 | 删除，不做等价替换 |
| 抑菌 / 杀菌 / 除菌率 99.9% | 若无完整评价依据即违规 | 拿不出完整依据就整句删掉 |
| 药物卫生巾 / 中药配方调理 | 把商品往药品上引 | 只描述添加成分本身，不描述作用于何种症状 |
| 私处修复 / 调节菌群平衡 | 医疗用语 + 无依据功效 | 删除 |
| 食品级 / 可食用级面层 | 自造概念误导 | 说明面层材质与实测指标 |
| 零添加 / 纯天然 / 无任何化学成分 | 绝对化倾向 + 举证困难 | 明确"不含某某物质"并以检测报告为准 |
| 全网最长 / 销量第一 / 最安全 | 《广告法》第九条绝对化用语 | 删除或改为可核验的具体描述 |
| 别家都有荧光剂，只有我们没有 | 贬低同行，涉商业诋毁 | 只讲自家检测结果，不做同业比较 |
| 孕妇产妇可用 / 婴儿也能用 | 特定人群适用性宣称需有依据 | 无依据不说；有依据说明来源 |
| 98% 抑菌率 | 数字须与报告完全一致，不得四舍五入放大 | 用报告原始数值，注明菌种/条件/机构 |

### "抑菌"的正确姿势
- 可写："对大肠杆菌、金黄色葡萄球菌、白色念珠菌有抑制作用"（菌种与报告一一对应）
- 可写：抑菌率数值 + 小字注明检测机构、菌种、试验方法、测试条件
- 不可写：消毒、灭菌、杀菌、除菌、广谱抑菌、全天抑菌（除有长效抑菌报告）、预防妇科、平衡菌群

### "消臭/净味/祛味"的正确姿势（2026-09-24 轮次更新，此前是"一律不可写"）
- 依据变了：**GB/T 45369-2025《吸收性卫生用纸制品及原材料 消臭效果评价方法》2025-09-01 已实施**，消臭宣称从"完全没有方法依据"变成"有国标方法可依"。术语明确"消臭效果包括净味、祛味等表述方式"——**写"净味""祛味"不能换词规避**
- 可写：有按 GB/T 45369（或团标等效方法）出具的消臭报告时，"祛味""净味""减少异味"+ 小字注明检测机构、方法与机理；引用团标判定数的注明团标号
- 不可写：拿不出报告时的任何消臭类表述；把 SAP/面层端的消臭数直接当成品宣称依据；用消臭报告顶替抑菌宣称（两条独立线）
- 注意：GB/T 45369 是**方法标准**，不给国标层合格线（第 13 章数字未取到）；可引用的量化门槛在 T/NAHIEM 39-2021 团标层（**必选**检知管法除臭率 ≥30.0%、注入氨气法 ≥50.0%、感官法 ≥30.0%）。详见 `references/raw-materials.md` 第 9 节与 `references/adjacent-categories.md` 第 2d 节
- "透气性"宣称：2026-11-01 起 **GB/T 47492-2026《卫生用纸制品 透气（湿）性能的测定》** 实施，届时"透气"将有国标方法可依；过渡期内只拿团标或企业方法数据的，注明方法来源

## 4. 中国广告协会《卫生巾广告自律规则》（中广协〔2008〕62号，非法律但写出监管常识标准）

- 第七条：吸水率、防回渗等功能表述**必须具有科学依据**
- 第八条：涉及具体功能的应提供证明文件，包括但不限于：① 国家认可的专业检测机构出具的检测报告；② 国际通用标准或 WHO 等机构文献；③ 正式出版的教科书；④ 医学或纸制品行业或学术组织的专家鉴定意见
- 第十条：广告对功效、性质、条件有表示的，应准确、客观且能被科学方法证实，不得夸大；涉及成分、含量、数据、统计资料的，应提供有效证明文件
- 第四条：不得以人体部位突出显示或模拟使用状态；演示液体不得为红色或相近色
- 第五条/第六条：广播电视广告避开用餐时段；不宜户外形式；不宜在针对少年儿童的媒体刊播

## 5. 直播电商（2026 新规）

《直播电商监督管理办法》（市场监管总局、国家网信办令第 117 号，2025-12-18 公布，**2026-02-01 施行**）：
- 直播间运营者、直播营销人员、MCN 机构均纳入监管
- 第十七条：平台须防范和处置直播间运营者、直播营销人员利用 **AI 等技术手段编造、传播虚假或引人误解的商业信息**，假冒他人进行商业宣传
- 违规发布直播营销信息按《广告法》相应条款处罚
- 市场监管总局已发布多批（至第六批）直播电商领域典型案例，直指虚假宣传、数据造假、违法广告、主体责任缺失

### 开播前十条自查
1. 产品证号与检验报告是否在手上，能否支撑打算说的功能
2. 脚本搜：医用、医护、临床、药、治、炎、痒、修复、抑菌、杀菌——命中即删或补依据
3. "缓解痛经"及一切近义表述全部清空，不做委婉替换
4. 所有数字指标（吸收量、长度、透气率、抑菌率）能否对应到报告具体项
5. "零添加""不含××"是否有检测依据
6. 有无最、第一、全网等绝对化用语
7. 有无拿其他品牌做贬低式比较
8. 有无把特定人群（孕产妇、婴幼儿）适用性说死
9. 直播间背景板、贴片、商品标题是否与口播口径一致（常是漏洞点）
10. 主播身份/人设是否真实（虚假人设已被多批典型案例查处）

## 6. 电商平台上架资质（平台规则快于法律）

平台要求通常严于法规，且经常变动。上架前必须逐平台确认当期规则。通用要求：
- 营业执照、商标注册证（R 标）或完整授权链
- 生产企业卫生许可证（消字号产品基本都会要）
- 近一年内 CMA 资质第三方检测报告
- 特殊类目另需行业资质
- 抖音等平台另需遵守《个护家清行业宣传规范》实施细则：不得使用医疗术语、不得暗示医疗作用效果、不得超出备案注册范围宣传功效、不得虚假暗示或承诺商品效果、不得滥用极限用语

**注意**：平台规则的存续和细节变化快，本条只列通用框架，具体以平台当期规则页面为准。

## 7. 企业标准（企标）

《标准化法》第二十七条：2017 年起**取消企业产品标准备案**，改为自我声明公开制度。
- 企业应公开其执行的强制性标准、推荐性标准、团体标准或企业标准的编号和名称
- 执行自行制定的企业标准的，还应公开产品/服务的功能指标和性能指标
- 通过企业标准信息公共服务平台（qybz.org.cn）公开
- **企标不得低于强制性标准**；低于国标/行标属违规（浙江省市场监管部门已查处过企业故意降低指标以规避竞争的案例）
- 卫生安全评价（备案类产品）可用企业标准作为质量标准，但不得低于 GB 15979 与产品性能国标
- 防骗提示：国家标准委明确不开展企业资质评价、不颁发"企业标准备案企业"证书牌匾，遇此类收费一律是诈骗
